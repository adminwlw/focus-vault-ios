# FocusVault iOS

`计时器`是一款 iPhone 原生 SwiftUI App，核心是本机加密保存私人照片和视频。公开界面提供手动计时与秒表，首次运行设置密码后可通过计时时长输入框进入本机私人空间。

## 已实现

- 默认手动输入分钟数，并提供通用快捷时长；支持暂停、继续、提前结束、后台恢复与本地通知。
- 秒表支持开始、暂停、继续、计次、复位和关闭 App 后恢复；记录页已替换，旧计时记录不再展示或新增。
- 正确密码从计时时长输入框进入；计时运行中也能用键盘“确认”进入，且不打断计时。错误密码不提示口令错误。
- 首次运行强制设置密码，公共设置页不显示私人空间入口。
- Keychain 口令验证和媒体密钥，AES-GCM 加密媒体与索引，退到后台立即锁定并遮挡任务切换快照。
- 系统照片选择器批量导入、导入成功后的系统原件删除选择、应用内相机、加密缩略图与新视频预览、照片缩放、视频播放、收藏、照片/视频筛选、批量全选、拍摄/导入时间排序和导出确认。
- 独立新建空相册、重命名、移动项目、导入到当前相册；删除相册保留其中媒体。旧版相册索引自动兼容读取。
- 私人空间首页右滑锁定退出，媒体详情提供锁定按钮；真正进入后台立即锁定，权限弹窗仅遮挡、不销毁导入流程。
- 30 天最近删除、恢复和永久删除。
- 使用独立备份密码的加密备份，备份保留空相册；恢复前验证所有项目，合并时不覆盖本机已有项目。
- Apple 隐私清单、商店披露文案和审核访问说明。
- iOS 16+，仅 iPhone；支持小屏、安全区域、横竖屏和动态字体，不包含账号、开发者云端、广告或订阅。

## 构建

项目文件由 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 生成：

```bash
brew install xcodegen
xcodegen generate
open FocusVault.xcodeproj
```

`main` 分支配置了 macOS GitHub Actions：生成工程、运行单元测试、分别在 iPhone SE（第 3 代）与 iPhone 16 Pro Max 模拟器运行 UI 测试，并产出未签名 IPA 和测试附件。构建只上传到该次 Actions 的私有 Artifact，不会自动提交 App Store。未签名 IPA 只能验证构建产物，不能直接安装到普通 iPhone。真机安装需要为 `com.sim360.focusvault` 配置 Apple Developer 证书和匹配的描述文件，或由测试者使用自己的开发者身份重新签名。

## 数据边界

私人媒体默认仅保存在 App 容器内。导入是复制操作，不会自动删除系统“照片”中的原件。卸载 App 前必须导出加密备份；口令与备份密码都无法由开发者找回。

0.2.0 可读取 0.1.1 的旧索引；新建或修改相册后会写入新版索引。旧版 App 不能读取新版索引，回退前应先导出备份，避免直接覆盖安装旧版。

当前加密与备份仍采用内存处理，单次备份媒体总量上限为 256 MB，恢复文件上限为 512 MB；更大的视频库应先分别导出大视频。长视频、iCloud 下载、系统删除确认、分享副本及跨设备恢复需在签名真机上复验。
